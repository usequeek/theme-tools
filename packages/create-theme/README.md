# @usequeek/create-theme

Start a theme for [Queek](https://usequeek.com) storefronts from the official
[starter](https://github.com/usequeek/theme-starter).

```bash
npm create @usequeek/theme my-theme
# or: pnpm create @usequeek/theme my-theme · yarn create @usequeek/theme my-theme
```

It copies the starter into `my-theme`, names the package after the folder and installs
dependencies with the package manager you ran it with (`-- --no-install` to skip). Then:

```bash
cd my-theme
npm run dev
```
